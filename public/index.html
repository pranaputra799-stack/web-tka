Pembahasan Soal

TKA English Strategy & Knowledge Hub

Kuasai tipe-tipe soal Reading Comprehension, teknik eliminasi pilihan jebakan, dan kosakata akademik kunci untuk meraih skor maksimal.

💡

Strategi Soal Main Idea

  • Skimming Paragraf Awal & Akhir: Gagasan pokok biasanya terletak pada kalimat pembuka teks eksposisi atau kesimpulan di paragraf penutup.
  • Hindari Pilihan Terlalu Sempit (Too Specific): Opsi yang hanya menyebutkan contoh detail dari 1 paragraf bukanlah main idea seluruh teks.
  • Perhatikan Kata Kunci Berulang: Konsep yang terus diulang dengan sinonim sering kali merupakan topik inti pembahasan.
🧩

Pilihan Ganda Kompleks (MCMA)

  • Verifikasi Setiap Pilihan Terpisah: Anggap setiap pilihan A sampai E sebagai pernyataan Benar/Salah (True/False) yang independen.
  • Cocokkan Frasa Eksplisit: Jangan berasumsi berdasarkan pengetahuan umum di luar teks; pastikan ada bukti kalimat dalam bacaan.
  • Waspadai Distractor Extreme: Pilihan yang memuat kata absolut seperti "always, never, completely, impossible" sering kali salah kecuali teks memang menyatakannya demikian.
📊

Menaklukkan Matching Table

  • Pahami Definisi Kategori: Identifikasi perbedaan dua kutub klasifikasi (contoh: Advantage vs Disadvantage, atau Agree vs Disagree).
  • Fokus pada Nada Kalimat (Tone): Perhatikan kata sifat atau kata kerja yang menunjukkan dampak positif atau negatif pada setiap pernyataan.
📖

Vocabulary Booster Akademik

  • Dissonance: Ketidakselarasan / pertentangan ide.
  • Inadvertently: Secara tidak sengaja / tanpa disadari.
  • Autonomy: Kemandirian / kebebasan menentukan arah.
  • Vulnerability: Kerentanan / kelemahan sistemik.
  • Exacerbate: Memperparah suatu situasi.
  • Feasible: Layak / memungkinkan untuk diwujudkan.

☁️ Panduan Hosting di Vercel & Database

Kabar baik: Aplikasi ini sudah dibuat 100% kompatibel dengan Vercel Static Hosting. Semua riwayat skor, jawaban, bookmark, dan streak tersimpan aman di Browser LocalStorage setiap kali kamu berlatih di HP atau laptop tanpa butuh database berbayar!

Jika kamu ingin sinkronisasi multi-device antar perangkat di kemudian hari, database cloud gratis terbaik untuk Vercel adalah:
• Turso (libSQL/SQLite Cloud): Sangat cepat, gratis, dan query persis sama dengan SQLite lokal.
• Supabase / Neon Postgres: Database cloud gratis dengan REST API instan.
